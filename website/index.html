The Architecture of Logic

Vespera is a curated system of distinct cognitive architectures solving specific problems in accuracy, speed, and memory tracking.

Hybrid Model Orchestration

Tasks are dynamically routed. Groq (Llama-3) is used for near-instant (500ms) game interactions, while Gemini Pro 1.5 is used for complex Cloud codebase reading.

The Truth Block Protocol

Retrieval-Augmented Generation that forces AI constraint. Only facts directly pulled from JSON endpoints (like the D&D SRD or Terra Docs) are used to prevent hallucination.

Aggressive Memory Hygiene

Built to run flawlessly on 1 vCPU / 1GB RAM instances. Using strict Python GC tuning, manual String Interning, and LRU eviction tactics to stay efficient.

Chain of Thought Enforcement

Internal logic blocks force the model to evaluate moderation actions or cloud calculations step-by-step prior to rendering an output to the user.
